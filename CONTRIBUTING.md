# Contributing

**Logs:** `NNN_desc.md` or `YYYY-MM-DD_desc.md` in `/logs`. Use [test_log_template](logs/test_log_template.md).

**Replacing [PROVISIONAL]:** Run tests per [testing_validation](docs/testing_validation.md); record in `/logs`; update README and remove tag.

**Rule:** No fabricated numbers. Use [TBD] or [PROVISIONAL] only for placeholders; document verification plan.
